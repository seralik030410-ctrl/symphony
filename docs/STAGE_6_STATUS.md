## Что работает

- **Лимиты контекста:** Настройки → Контекст и память → Лимиты модели. Окно и резерв ответа сохраняются отдельно для чата; превышение предела модели и изменения во время ответа блокируются. Ollama получает `num_ctx`/`num_predict`, совместимый API — `max_tokens` и локальную проверку бюджета.
- **Индекс:** текстовые файлы, PDF, DOCX, PPTX и XLSX разбиваются на фрагменты в SQLite FTS5. В prompt входят только найденные отрывки, а не весь большой файл. Источники и позиции фрагментов видны в ответе. Изменённый SHA-256 исключает устаревшее содержимое и предлагает переиндексацию. Отключение индекса сохраняет сам файл.
- **Изолированное извлечение:** фиксированные PDF/Office-парсеры выполняются в отдельном offline Docker-контейнере с read-only input/worker, без worktree и домашней папки. Есть ограничения размера, распаковки, текста, RAM/PID/CPU и времени; отмена удаляет контейнер. Без Docker нет скрытого host fallback.
- **Смысловая память:** выбранная модель через единый Gateway сжимает старые целые сообщения в Facts, Decisions, Open tasks и Artifact index. Автоматический порог — около 72% доступного входного бюджета. Последние десять сообщений (иногда одиннадцать для сохранения пары) остаются дословными. Исходные сообщения не удаляются.
- **Версии и происхождение:** каждый snapshot хранит source message IDs, модель и usage. Некорректный JSON, отмена и конфликт версии не публикуют частичную память. Есть ручное сжатие, правки, очистка и просмотр версий. Очистка создаёт пустую версию, не удаляет историю; при новом заполнении окна возможно повторное сжатие.
- **Полный бюджет:** учитываются инструкции, схемы инструментов, история, память, фрагменты, изображения и резервы ответа/наблюдений. Если оставшиеся целые сообщения не помещаются, возвращается понятная ошибка, а не молча обрезанный запрос. Usage сжатия включён в итоговые токены turn, но не суммируется с текущей занятостью контекста.
- **Вложения:** очередь до восьми файлов, миниатюры, удаление черновиков, восстановление после refresh; Retry сохраняет исходное вложение и режим обработки. Отправленные файлы защищены проверками целостности и не удаляются как черновики. Файлы другого чата недоступны.
- **Vision и OCR:** Ollama сообщает возможности через `/api/show`. Для неизвестного совместимого API есть явные сохраняемые overrides vision/max-context и сброс. Эти параметры относятся ко всем чатам выбранной provider/model. Текстовая модель не получает изображения под видом текста; пользователь может выбрать локальный OCR в Tesseract и передать модели только распознанный текст.
- **Спокойный интерфейс:** расширенные параметры находятся в Settings, память и возможности модели раскрываются по запросу. Обычный короткий разговор не получает обязательный дополнительный вызов модели или document router.

## Честные ограничения

- Retrieval лексический FTS5, без отдельной embedding-модели/векторного сервера. Для поиска нужны слова из источника; это не обещание безошибочного семантического поиска.
- Предварительные токены — оценка, а не точный tokenizer: текст примерно characters/3, overhead сообщений и 2 048 токенов на изображение. Реальный provider usage отображается отдельно. Настройка окна не расширяет реальную ёмкость удалённой модели.
- Память создаётся моделью и может потерять нюанс или ошибиться. Для проверки доступны исходные сообщения, версии и ручные правки. Сжатие занимает время и расходует токены выбранного provider.
- Документы до 25 MB, изображения до 10 MB и 40 млн пикселей, восемь вложений в черновике. Извлечение до 2 млн знаков/60 секунд; PDF до 1 000 страниц; ZIP до 5 000 записей/80 MB суммарно/30 MB на запись. Превышение — явная ошибка, не успешная частичная индексация.
- OCR — распознавание текста PNG/JPEG/WebP, не понимание диаграмм. Автоматическое OCR всех страниц сканированного PDF не реализовано: прикрепите изображения нужных страниц. Изображения передаются vision-модели только с текущим turn.
- Хранилище single-user/local-only; не публикуйте API в интернет. Версии памяти, артефакты и корзина автоматически не очищаются.
- Сохраняются некритичные предупреждения зависимостей pytest и Vite о JS chunk больше 500 KB. Они не являются ошибками тестов/сборки.

## Запуск

`START.bat` запускает Docker/Ollama/backend и открывает [Symphony](http://127.0.0.1:8765). Production frontend и API используют **8765**, dev Vite — **5173**. Launcher не убивает уже работающий backend: после изменения Python нужен его перезапуск, а не только обновление страницы.
