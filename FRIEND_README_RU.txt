SYMPHONY 2.0 — УСТАНОВКА ДЛЯ ДРУГА (WINDOWS 10/11 x64)

До первого запуска установите и один раз откройте:
1. Python 3.12 или новее: https://www.python.org/downloads/windows/
   При установке включите "Add python.exe to PATH".
2. Docker Desktop: https://www.docker.com/products/docker-desktop/
   Используйте Linux containers; дождитесь запуска Docker Engine.
3. Ollama: https://ollama.com/download/windows

Затем распакуйте ZIP полностью в обычную папку и запустите FRIEND_SETUP.bat.
Не запускайте BAT прямо внутри ZIP. Первый запуск спросит подтверждение, создаст
локальную .venv, установит Python-зависимости, соберёт Docker runtime и скачает
qwen3.5:9b (~6.6 ГБ), если модели ещё нет. Желательно 18–25 ГБ свободного места.

После настройки для обычного запуска используйте START.bat. Интерфейс откроется:
http://127.0.0.1:8765

Node.js не нужен, если в пакете есть frontend/dist/index.html. Git тоже не нужен.
Обычный чат требует Ollama, но не Docker. Docker нужен для инструментов, кода,
документов и OCR. Все чаты хранятся только в папке data на компьютере друга.
Никогда не пересылайте обратно папку data: там находятся его чаты и файлы.

Приложение локальное и не имеет многопользовательской авторизации. Не меняйте
адрес 127.0.0.1 и не публикуйте порт 8765 в интернет/локальную сеть.

Если установка прервалась, исправьте указанную причину и снова запустите
FRIEND_SETUP.bat — повторный запуск безопасен. Диагностика находится внутри
приложения: Настройки → Общее → Диагностика.

Необязательно: облачная модель через API
----------------------------------------
Запустите CONFIGURE_API.bat, выберите Z.AI/GLM, Qwen/DashScope или другой
OpenAI-compatible API, затем перезапустите Symphony. Локальная Ollama останется
доступна. Ключ хранится только в локальном .env и не должен никому отправляться.
Подробности: API_PROVIDERS_RU.md
